# 급락 대응 v0.3 실제 브라우저 추가 검증

검증일: 2026-11-20, Asia/Seoul. Windows 네이티브 Microsoft Edge의 1440×852 화면에서 `http://127.0.0.1:5173` 개발 앱을 관측했다. 루트 에이전트가 Sky를 통해 실제 차트 캔버스를 클릭하여 날짜를 선택하고, 기존 오른쪽 신호 패널을 스크롤하거나 근거 상세를 펼쳤다. 이 문서는 그 회차의 PNG와 화면 텍스트를 대조한 기록이다. 날짜별 API 호출 결과나 jsdom의 차트 mock으로 브라우저 관측을 대체하지 않았다.

## 이전 중단 기록과 이번 회차의 구분

이전 회차에는 Computer Use가 현재 URL을 확신하지 못해 UI 조작을 중단했다. 당시 기록은 상위 [frontend_verification.json](../frontend_verification.json)에 남아 있다. 해당 회차의 `browser_synthetic_candidate_verified=false`와 중단 사유를 삭제하거나 당시에도 검증한 것으로 바꾸지 않는다.

이번 새 회차에는 현재 로컬 URL을 확인한 뒤 허용된 기존 UI 조작으로 추가 관측을 완료했다. 저장한 캡처에도 Edge 주소 표시줄의 `127.0.0.1:5173`이 나타난다. 이는 이전 중단을 우회한 기록이 아니라, URL이 확인된 새 회차의 별도 증거다.

## 조작 및 판독 기준

- 기존 `1D`, `캔들 선택`, `급락 대응 · 실험` 토글과 캔버스 클릭을 사용했다. 새 날짜 입력 UI나 URL 날짜 주입 기능을 만들지 않았다.
- 차트 범례의 날짜는 hover만으로 바뀔 수 있으므로, 오른쪽 `신호` 패널의 선택 날짜와 날짜별 화면 텍스트도 함께 확인했다. 일부 PNG는 실험 섹션을 보기 위해 패널 상단이 스크롤되어 있으며, 같은 시점 TXT가 선택 날짜와 전체 텍스트를 보완한다.
- 신규는 `당일 새 발생`, 기존 후보는 `이전 후보 유지` 및 원래 `발생` 날짜로 구분했다. 같은 제목이 유지 영역에 보인다고 새 후보 발생으로 세지 않았다.
- 상단의 기존 독립 신호 롱·숏 숫자와 `급락 대응 · 실험` 섹션을 분리해 읽었다. 화면에 표시된 후보·관찰·종료 사건을 거래 수나 수익성으로 해석하지 않았다.

## 결론 및 이번 추가 검사에서 하지 않은 항목

고정 데이터의 신규→유지→만료와 이전 후보 연결, 합성 데이터의 첫 후보·급락 경고 공존, 재지지 신규·유지, 반복 접촉 중복 방지, 두 후보 무효화, 동일 지지 버전의 이탈 후 회복, 다음 날 사건 비반복을 실제 Edge 화면에서 확인했다. 선택한 표본 화면에서 새 제품 UI 오류는 관찰되지 않았다.

기능 OFF와 주봉 전환은 **이번 추가 브라우저 회차에서 재검사하지 않았다.** 해당 동작을 포함한 기존 프런트 자동 회귀 154개 통과 및 실제 API→jsdom 패널 검사는 [이전 검증 기록](../frontend_verification.json)의 별도 증거다. 이 문서로 이번 회차에 그 브라우저 조작까지 수행했다고 확대 해석하지 않는다.

실제 수동 지지에서의 첫 제동·트랩은 아직 검증하지 못했다. 고정 일봉은 수동 지지 미확인이고, 수동 지지 경로의 화면 사례는 명시된 합성 입력만 사용했다. 미래 정보 불변성·전체 리플레이·백엔드 검사와 데이터 보존 또는 기존 사고 기록도 이 브라우저 표본 검사로 대체하거나 수정하지 않는다. 체결·포지션·수익성·실제 주문·main 병합·운영 배포는 이 검증의 대상이 아니다.
