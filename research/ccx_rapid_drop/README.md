# CoinCloudX · 급락 대응 관찰기 v0.1

`f9ade54ee9691eff75cca7ed719cff47ce75132b`를 기준으로 한 독립 연구 초안. 기본 꺼진 운영 기능도 아니고, 앱에 연결되지 않은 별도 프로그램이다. 운영 코드·DB를 읽고 쓰는 작업, 거래 실행, 포지션·손익 계산은 없다.

## 실행

Python 3.10 이상. 압축을 풀고 그 폴더에서 `python -m unittest -v` 실행. 엔진과 단위 테스트는 표준 라이브러리만 쓴다. `test_log.txt`는 개발 시 실행 결과다.

전체 고정 일봉을 보려면 본인 PC의 CoinCloudX checkout 및 `backend/requirements.txt`가 설치된 프로젝트 Python을 사용한다. 아래 `python`을 해당 가상환경 Python으로 대체할 수 있다. 저장소를 수정할 필요는 없다.

```sh
python replay.py --repo /path/to/trading_app --config example_config.json --levels levels.example.json > observations.jsonl
```

`replay.py`는 기존 `compute_candle_shape` 결과를 받아 그대로 사용한다. 새로운 망치/도지 정의는 없다. 샘플 설정의 모든 값은 분기 작동을 보여 주기 위한 가정이며 최적값·운용 기준이 아니다. 실제 지원 가격 없이 실행할 수 있으나, `levels.example.json`이 빈 목록이면 수동 지지에서의 직접 도지 후보는 발생하지 않는다. 고거래량 음봉 기준의 재시험은 여전히 관찰한다. 실행기는 고정 마감 일봉 전용이다. 운영용 시세 어댑터는 없다.

## 입력과 시간

- 날짜순으로 누락·중복 없는 마감 일봉만. 신규·수정 도형을 사용하는 경우 `key`, `bottom`, `top`, `known_from`, `through`가 필요하다. 날짜는 ISO `YYYY-MM-DD`이고 시작·종료를 포함한다. 수평선은 `bottom == top`. 최초 등록뿐 아니라 *해당 버전의 좌표가 판정 당시 알려져 있던* 날짜에만 넣는다. 이력이 없는 과거 손그림을 데이터로 넣지 않는다. 같은 도형의 버전이 중첩되지 않도록 입력에서 확인하고, 버전마다 다른 키를 쓴다. 프로그램이 그 역사적 진위를 복원하지는 않는다.
- 기울기는 인접한 두 구간의 봉당 로그수익률 `log(끝 종가 / 시작 종가) / 봉 수`를 비교한다. 최근 하락 속도가 최소값을 넘고 이전보다 더 가팔라지면 급락 가속. 이미 가파르기만 한 하락과 새 가속을 구분한다. 감지 후 관찰 기간은 설정값이다. 줌·화면 각도·미래 봉에 의존하지 않는다.
- 거래량은 당일 제외 직전 평균 대비 배수. 데이터 부족·평균 0은 고거래량이라고 가정하지 않는다. RSI는 넣지 않았다.

## 두 진입 가설 (모두 후보/관찰, 주문 아님)

1. 가속 관찰 기간에 지지를 시험하고 종가가 버틴 고거래량 도지: `direct_doji_candidate`. 해당 봉을 재시험의 기준으로도 기억한다. 지지선을 방금 밑에서 위로 회복한 봉을 지지 재시험과 혼동하지 않는다. 거래량이 낮은 지지 도지는 `doji_anchor_watch`.
2. 고거래량 장대음봉: `volume_red_watch_only`. 마지막 매도였다고 단정하지 않고 기준 봉만 둔다. 반등을 종가로 확인한 봉(`bounce_observed`) **이후의 다른 봉**에서 기준 몸통 종가 부근을 다시 시험하면 `retest_observed`. 반전 모양까지 있으면 `retest_preferred`. 모양 없는 첫 재시험에서 기준을 곧바로 폐기하지 않는다. 첫 꼬리 저점을 깨도 종가가 기준대에 복귀하면 `first_wick_undercut_recovered`. 첫 반등 봉 안에서의 가격 순서를 추측하지 않는다.

`anchor_lost_on_close`는 기준대 하단 종가 이탈, `anchor_expired`는 유효기간 경과다. 별도의 더 낮은 존에서 새로 나온 첫 도지는 앞선 기준이 무효가 됐다면 새로운 후보로 처리한다. `reaction_levels`는 당일 지지 반응, `unrecovered_levels`는 유효기간 내에 관찰된 하향 이탈 후 아직 종가로 완전히 회복하지 못한 선·존 목록. 이것은 저항의 확정, 목표가 또는 모든 롱을 금지하는 조건이 아니다. `anchor_day`는 그 행에서 참조하는 기준 봉 날짜다.

## 무엇이 아직 실험인가

- 첫 저점 몸통의 기준은 현재 **종가**라는 가정. 허용 폭 이내의 마감은 재지지, 그 아래 마감은 기준 무효로 둔다. 반등 폭·기울기 비교 기간·거래량 배수·대기 기간은 구성 파일로 분리했다. `retest_preferred`에 포함한 도지/망치/역망치 목록도 후속 검증 대상이다.
- 한 번에 한 기준 봉만 추적하고, 더 확인된 사건이 있으면 중복 알림을 피한다. 지지 이탈 후 복귀 판단은 지지선 및 직사각형 존 용도이며 추세선/다중 시간대/분할 진입/매도 체결을 모델링하지 않는다. 지지 입력이 불완전하면 결과도 불완전하다. 과거 저점 신호를 나중에 소급하여 생성하지 않는다.
- 테스트 19개: 18개는 합성·입력·미래 봉 불변성 테스트, 1개는 실제 저장소 고정 데이터의 첫 8일 OHLCV로 기울기 계산을 실행한 스모크 테스트다. `fixture_excerpt.csv` 출처는 위 커밋의 `backend/tests/fixtures/BTCUSDT_1d_2022-01-01_2026-10-28.csv`, 2022-01-01~08이다. 사용자가 첨부한 스크린샷의 거래는 재현하지 않았다. 전체 데이터 리플레이, 전체 앱 테스트, 배포, 성과 검증은 실행하지 않았다.
